# Steer

iPhone client for driving Claude Code and Codex on your own machines over SSH.
Read [docs/design.md](docs/design.md) (why and UX) and
[docs/helper-protocol.md](docs/helper-protocol.md) (app ↔ helper wire format)
before changing behaviour.

## Layout

- `helper/steerd.py` — host helper, single file, standard library only,
  Python 3.8+. Translates Claude stream-json and Codex app-server into one
  timeline model. Tests: `make helper-test` (must pass on macOS's
  `/usr/bin/python3` 3.9 too). Bump `VERSION` whenever it changes: the app
  reinstalls the helper when versions differ.
- `App/` — SwiftUI app. `Model/HelperLink.swift` (SSH + NDJSON),
  `Model/AppModel.swift` (hosts, connection, session list),
  `Model/ChatModel.swift` (one conversation), `Views/`.
- `Packages/HeelerSSH` — SSH package from Heeler (Apache-2.0). Keep its
  pinned artifacts as they are.
- `Steer.xcodeproj` is generated by xcodegen from `project.yml`; run
  `make project` after adding or removing files.
- `scripts/` — TestFlight upload (`testflight.sh`, `beta.sh`, `asc.sh`);
  see [docs/releasing.md](docs/releasing.md).

## Conventions

- Swift 6 strict concurrency, iOS 18+. No force unwraps or `try!` outside tests.
- UI text is Chinese, written as SwiftUI literals or `String(localized:)`.
- Remote commands go through `HelperLink.sh(...)` (`/bin/sh -c '…'`) because
  login shells may be fish. Scripts must not contain single quotes.
- Private keys and passwords stay in the Keychain.
- Real-agent checks (`helper/tests/live_check.py`, `UITests/`) cost a little
  usage; use the smallest models and throwaway project folders.
